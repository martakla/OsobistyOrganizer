# OsobistyOrganizer - Todo App

A simple web application for managing personal tasks.

The app allows users to register and log in locally, add tasks, assign categories and deadlines, display the time left until a task is due, filter tasks by category, mark tasks as completed, and delete them.

## Live Demo

https://osobisty-organizer-umvv.vercel.app/

## Features

- local user registration
- local user login
- adding new tasks
- assigning categories to tasks
- setting task deadlines
- displaying time left until the deadline
- filtering tasks by category
- marking tasks as completed
- deleting tasks
- simple and clean interface
- responsive layout

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel
